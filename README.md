# 云智工业互联平台 - HTML 原型

7 个页面原型文件，用于研发预览。

## 页面列表

1. **人才管理.html** - 人才管理模块
2. **任务管理.html** - 任务管理模块
3. **工单管理.html** - 工单管理模块
4. **证书管理.html** - 证书管理模块
5. **项目列表.html** - 项目列表页面
6. **项目空间.html** - 项目空间页面
7. **新增页面.html** - 新增功能页面

## 技术栈

- Tailwind CSS (CDN)
- Font Awesome (CDN)
- 纯 HTML + JavaScript

## 本地预览

```bash
python3 -m http.server 8080
```

访问 http://localhost:8080
