## 🛠 技术栈

- **CSS 框架**: Tailwind CSS (CDN)
- **图标库**: Font Awesome 6.4.0
- **开发方式**: 纯 HTML + JavaScript
- **设计风格**: 玻璃拟态 (Glassmorphism)
